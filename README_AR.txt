# WILD HUNT ONLINE — Godot Starter Project

هذا مشروع بداية قابل للتشغيل على Godot 4.7.2، وليس لعبة نهائية بمستوى PUBG بعد.

## التشغيل
1. فك ضغط ملف ZIP.
2. افتح Godot.
3. اضغط Import / استيراد مشروع موجود.
4. اختر ملف `project.godot` الموجود داخل مجلد `WILD_HUNT_ONLINE_Godot`.
5. افتح المشروع واضغط زر التشغيل ▶.

## الموجود حالياً
- عالم ثلاثي الأبعاد أولي مع أرض وأشجار وإضاءة وسماء.
- شخصية لاعب بسيطة.
- كاميرا خلفية مع تبديل لمنظور أول.
- تحكم لوحة مفاتيح، ولمس الهاتف (يسار الشاشة للحركة ويمينها لتحريك الكاميرا).
- زران على الشاشة لتبديل المنظور والقفز.
- مجسمات غزلان تجريبية.

## ملاحظات مهمة
- هذه نسخة تأسيسية قابلة للتطوير، وليست لعبة صيد مكتملة أو رسومات PUBG.
- الحيوانات حالياً مجسمات تجريبية ثابتة؛ لا توجد بعد أنظمة صيد أو متجر أو كلاب أو حفظ أو لعب جماعي.
- تم اختيار وضع GL Compatibility لتسهيل التشغيل على أجهزة أندرويد.
- احفظ نسخة احتياطية قبل تعديل الملفات.
